# Prompts reutilizáveis

## Criar um repositório
"Preciso de ajuda para criar um repositório do meu projeto e subir para o GitHub, como faço isso?"

## Desfazendo alterações indesejadas
"Fiz uma alteração que não deveria e acabei estragando o projeto, como faço para reverter?"

## Importando projetos
"Encontrei um projeto open-source interessante no GitHub e gostaria de colocá-lo no meu computador para fazer alterações, como faço isso?"

## Solicitando alterações
"Modifiquei um projeto open-source do GitHub e gostaria de enviar minhas alterações para o dono do projeto. Como posso fazer isso?"

## Mesclando branches
"Como faço para juntar um branch alternativo com o branch principal?"
